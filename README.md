
# Energy-Aware Window Cleaning Robot

### ME4101A Final Year Project

**National University of Singapore (NUS)**  
**College of Design and Engineering (CDE)**

## Project Overview

This project focuses on developing an energy-efficient coverage path planning (CPP) and control framework for a low-cost suction-based window-cleaning robot operating on vertical glass surfaces.

The research investigates how locomotion direction, suction adhesion, turning manoeuvres, and cleaning duration influence the robot's total energy consumption.

The objective is to develop and evaluate energy-aware coverage strategies that minimise energy consumption while maintaining complete surface coverage.

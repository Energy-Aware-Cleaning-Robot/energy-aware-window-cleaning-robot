# energy-aware-window-cleaning-robot
Energy-Aware Window Cleaning Robot

ME4101A Final Year Project (Dissertation)

National University of Singapore (NUS) • College of Design and Engineering (CDE)

Project Title: Energy-efficient path planning and control for low-cost window cleaning robot for high-rise buildings

Project Overview

This Final Year Project focuses on developing a low-cost suction-based window-cleaning robot capable of navigating vertical glass surfaces using energy-aware Coverage Path Planning (CPP).

The project investigates the energy consumption associated with locomotion, suction adhesion, turning and cleaning operations to develop an energy-efficient coverage strategy.

Key Research Objectives

Develop a low-cost suction-based wall-climbing robot.

Characterise direction-dependent locomotion and adhesion energy consumption.

Develop a mathematical energy consumption model.

Simulate and compare different CPP algorithms.

Evaluate conventional and energy-aware CPP strategies.


# Software Development

The software subsystem focuses on developing and
evaluating energy-aware Coverage Path Planning (CPP)
algorithms for vertical glass-cleaning robots.

## Software Components

### 1. Energy Consumption Model

A mathematical model estimates energy consumption
associated with locomotion, adhesion, turning
and cleaning.

[View Energy Model](/software/energy-model)

### 2. Coverage Path Planning

Conventional CPP algorithms are compared with
energy-aware planning strategies.

[View CPP Algorithms](/software/cpp)

### 3. Python Simulation

A simulation framework evaluates coverage trajectories,
path length, energy consumption and completion time.

[View Simulation](/software/simulation)

## Development Objectives

- Implement conventional coverage strategies.
- Develop an energy-aware CPP algorithm.
- Compare energy consumption across trajectories.
- Evaluate coverage efficiency.
- Validate simulation results experimentally.
